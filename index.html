나의 기본 보스 설정

매주 잡는 보스를 선택해 주세요. 주간 보스는 최대 12개, 월간 보스는 별도로 선택할 수 있어요. 추천은 입장 레벨과 전투력으로 잡을 수 있는 보스를 고르고, 1인 컷을 넘으면 1인·55%를 넘으면 2인 기준 결정석 가격으로 계산합니다. 실제 클리어 가능 여부에 맞춰 난이도와 파티 인원을 바꾸세요.

Nexon API 연결

메이플스토리 API 키를 입력하면 캐릭터 사진과 정보를 조회할 수 있어요. 키는 이 브라우저의 localStorage에만 저장되어 새로고침하거나 다시 방문해도 연결이 유지돼요. 키는 Nexon 공식 API에만 전송하며, 기록 내보내기(JSON) 파일에는 들어가지 않아요. 공용 PC에서는 저장하지 마세요.

저장된 키는 연결 해제로 언제든 지울 수 있어요. 키를 바꾸려면 새 키를 입력하세요.
