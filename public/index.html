나의 기본 보스 설정

매주 잡는 보스를 선택해 주세요. 주간 보스는 최대 12개, 월간 보스는 별도로 선택할 수 있어요. 신규 캐릭터는 레벨 입장 조건과 최고 난이도 가격 기준으로 추천됩니다. 실제 클리어 가능 여부에 맞춰 난이도와 파티 인원을 바꾸세요.

결정석 가격 수정

파티 인원으로 나누기 전 결정석 1개 가격을 입력하세요.

캐릭터와 난이도별로 저장돼요. 다른 캐릭터에는 적용되지 않습니다.

Nexon API 연결

메이플스토리 API 키를 입력하면 캐릭터 사진과 정보를 조회할 수 있어요. 키는 Nexon 공식 API에만 전송하며, 이 탭에서만 사용합니다. 새로고침하면 다시 입력해야 해요.

키는 브라우저 저장소나 기록 내보내기 파일에 저장하지 않아요.
