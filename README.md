# 메이플 위클리

메이플스토리 캐릭터별 주간 보스 루틴과 결정석 수익을 관리하는 한국어 웹 앱입니다.

## 실행

Node.js 24 이상이 필요합니다. 런타임 의존성이나 빌드 과정은 없습니다.

```sh
npm start
```

기본 포트는 3000입니다. 개발 중 자동 재시작은 `npm run dev`, 검증은 `npm test`를 사용하세요. 클라우드 작업에서는 기존 체크아웃을 사용하며 추가 Git worktree를 만들 필요가 없습니다.

## 사용 방법

1. 내 캐릭터의 `＋` 버튼에서 이름을 입력하고 **직접 등록**합니다. 처음 보이는 캐릭터는 데모이며 실제 캐릭터를 등록하면 자동으로 사라집니다. **순서 변경** 버튼에서 ↑ ↓로 위치를 바꾸고 **순서 저장**을 누릅니다. 일반 캐릭터 선택은 순서를 바꾸지 않으며 취소하면 원래 순서를 유지합니다.
2. **기본 보스 설정**에서 매주 잡는 보스를 선택하고 저장합니다. 레벨이 있는 기존 캐릭터도 **레벨 기준 추천**을 누른 뒤 저장하면 추천 목록과 난이도를 적용할 수 있습니다. 취소하면 기존 설정을 유지합니다.
3. 보스 목록과 처치 체크는 캐릭터당 한 주 최대 **12개**입니다. 레벨이 있는 신규 캐릭터는 입장 가능한 보스 중 최고 난이도 가격이 높은 순으로 주간 최대 12개와 입장 가능한 월간 보스를 기본 선택합니다. API 조회 레벨 또는 직접 등록 시 입력한 레벨을 사용합니다. 이는 입장 레벨 기준이며 전투력·선행 퀘스트로 판단하는 실제 클리어 추천은 아닙니다. 레벨 미입력 시 기존 기본 12개를 사용하며, 이전에 저장한 사용자 목록은 유지합니다. 난이도를 아직 지정하지 않은 보스는 카오스 또는 하드를 우선 적용합니다 (더스크: 카오스, 윌·루시드: 하드). 직접 저장한 난이도는 유지합니다. 보스별 난이도와 파티 인원(1~6명)을 선택합니다. 같은 보스의 난이도는 하나만 선택할 수 있습니다.
4. 보스의 수익 금액을 눌러 결정석 판매가를 수정합니다.
5. 보스 아래 **동행 메모 추가**를 눌러 함께 가는 사람이나 약속 시간을 적습니다. 저장한 메모는 목록에 표시되고, 캐릭터별로 저장되어 다음 주에도 유지됩니다. 메모창에서 수정·삭제할 수 있습니다 (최대 500자).
6. **월간 보스** 탭에서 검은 마법사를 별도로 체크할 수 있습니다. 한국 시간 매월 1일에 초기화되며 주간 12개 제한에 포함되지 않습니다.
7. 보스 목록은 파티별 수익을 기준으로 오름차순 정렬합니다. 전체 캐릭터 월간 예상액 목록도 낮은 금액부터 표시합니다. **전체·미완료·완료** 필터로 해당 상태의 보스만 표시합니다. 체크를 변경하면 현재 필터 목록도 즉시 갱신됩니다.
8. **현재 메소 시세**에 1억 메소당 원화 가격을 입력하면 획득 수익의 현금 가치를 `floor(수익 / 100,000,000 × 시세)`로 표시합니다. 기본 시세는 1,500원이며 직접 변경할 수 있습니다. 기존에 입력한 유효 시세는 유지합니다. 시세는 모든 캐릭터에 공통이며 자동 저장됩니다.
9. **이번 달 예상 수익**은 모든 등록 캐릭터의 선택된 주간 보스를 매주 모두 완료하는 경우의 합계입니다. 난이도·파티 인원·직접 수정 가격을 반영하며 기본 4주, 선택 시 5주로 계산합니다. 월간 예상액은 **(주간 수익 × 주수) + 선택한 월간 보스 결정석 1회분**이며, 두 항목 모두 파티 인원으로 나눈 값입니다. 캐릭터별 월간 예상액과 현금 환산도 표시합니다. 데모와 보관된 이전 보스는 제외합니다. 실제 월간 보스 획득액은 월간 탭에서 별도로 확인합니다.
10. **선택한 주간 보스 모두 체크**는 필터/검색과 관계없이 현재 주간 루틴 전체를 체크하거나 해제합니다. 일부만 완료했다면 중간 상태로 표시합니다. 이전에 체크한 목록 외 보스를 포함해 12개 한도를 넘으면 변경하지 않습니다.
11. **캘린더** 탭에서 날짜별 보스 약속을 추가합니다. **함께 가는 사람 / 보스 / 시간** 한 칸에 `달빛님 / 하드 루시드 / 오후 7시`처럼 입력하고 저장합니다. `오후 7시`, `19시`, `19:30`, `오후 7시 30분` 등을 24시간 표기로 자동 변환해 `19:00 ≫ 달빛님 / 하드 루시드` 순서로 표시합니다. 시간은 생략할 수 있습니다. 별도 시간/메모 입력칸은 없으며, 기존 일정의 메모는 보존합니다. 같은 날 여러 일정을 추가할 수 있고 각 일정의 색상은 자동으로 달라집니다. 일정을 누르면 수정·날짜 이동·삭제할 수 있습니다. 캘린더는 전체 캐릭터가 함께 사용하며, 기록 내보내기에도 포함됩니다.
12. 처치한 보스를 체크하면 `floor(결정석 판매가 / 파티 인원)`을 합산합니다.

**가격 기준:** 사용자가 제공한 `보스 결정석 가격.xlsx`의 C열 **변경 가격** 46건을 정수 메소로 변환해 적용했습니다. 파일에 없는 고난도 8건은 커뮤니티 공개 참조값으로 별도 표시합니다. 원본 엑셀에는 적용 날짜가 없어 날짜를 추정하지 않았습니다. 출처/구분은 [PRICE_SOURCES.md](PRICE_SOURCES.md)에 기록했습니다. 실제 판매가와 다르면 수정할 수 있으며, 기존에 직접 입력한 가격은 덮어쓰지 않습니다. **기본 가격 복원**을 누르면 해당 난이도의 표 기본값을 적용합니다.

수익은 결정석만 포함하며 아이템 드롭 수익은 포함하지 않습니다. 일반/리부트 월드 배율을 자동 적용하지 않습니다.

기본 보스 목록, 가격, 인원과 처치 체크는 캐릭터별로 브라우저 `localStorage`에 저장됩니다. 한국 시간 목요일 00:00부터 새 주로 계산하며, 새 주에는 처치 체크만 새로 시작하고 기본 목록과 가격은 유지합니다. 지난 주 기록은 내보내기 데이터에 보존됩니다. 보스별 변경 사항은 현재 주 수익에 즉시 적용됩니다. 데이터는 브라우저 간에 동기화되지 않습니다. `기록 내보내기`로 JSON 백업이 가능합니다. 가져오기 UI는 아직 제공하지 않습니다.

## GitHub Pages 배포

서버 없이 `public/`의 정적 파일만 게시합니다. API 키가 없어도 직접 등록과 보스 기록 기능을 사용할 수 있습니다. API 키를 입력하면 브라우저가 Nexon 공식 API를 직접 호출해 캐릭터 사진과 기본 정보를 가져옵니다. 사이트 주소가 달라지면 기존 브라우저 기록은 자동 이전되지 않습니다.

배포용 브랜치를 만들고 올리는 명령:

```sh
# 먼저 public/ 변경 사항을 커밋한 뒤 실행합니다.
npm run deploy:pages
```

이 명령은 현재 커밋의 `public/` 디렉터리만 `gh-pages` 브랜치로 푸시합니다. 강제 푸시는 사용하지 않습니다. 새 Git worktree를 만들거나 현재 체크아웃을 바꾸지 않습니다. GitHub 읽기/쓰기 권한이 필요합니다.

최초 한 번 GitHub 저장소의 **Settings → Pages**에서:

- Source: **Deploy from a branch**
- Branch: **gh-pages**, 폴더: **/(root)**
- **Save**

GitHub가 배포를 완료하면 Pages 설정 화면에서 실제 사이트 URL을 확인하세요. 예상 주소는 `https://izi0623.github.io/my-maple-checker/`이며, 배포 상태를 확인하기 전에는 접속 가능한 주소로 간주하지 않습니다. 저장소가 비공개라면 계정 플랜에 따라 Pages 사용이 제한될 수 있습니다. 이 경우 저장소 공개 여부는 사용자가 결정해야 합니다.

## 캐릭터 사진 조회

1. **Nexon API 연결**에서 개인 메이플스토리 API 키를 입력합니다. 키는 채팅에 보내지 마세요.
2. 이미 등록한 캐릭터는 **사진·정보 새로 불러오기**를 누릅니다. 새 캐릭터는 `＋`에서 이름을 입력하고 **사진·정보 불러오기**를 누릅니다.
3. 같은 이름으로 직접 등록해 둔 보스 설정과 메모는 유지하고, 사진·월드·직업·레벨만 업데이트합니다.

키는 이 탭의 메모리에서만 사용하며, `localStorage`, 내보내기 JSON, 저장소에 저장하지 않습니다. 새로고침 후 다시 입력해야 합니다. 연결 해제로 메모리의 키를 제거할 수 있습니다. 키를 포함한 헤더는 `https://open.api.nexon.com/maplestory/v1/id`와 `character/basic`에만 보냅니다. 키는 Nexon 조회에 필요한 개인 자격 증명이므로 신뢰하는 자신의 브라우저에서 사용하세요.

GitHub Pages에는 서버가 없으므로 Nexon API의 브라우저 접근 허용(CORS), 키 권한, 호출 한도가 필요합니다. 접근 제한이 발생하면 화면에 원인을 안내하고 직접 등록을 계속 사용할 수 있습니다. 실 API 호출은 개발 환경의 네트워크 정책과 유효한 개인 키가 없어 검증하지 못했으며, 모의 응답으로 흐름을 검증했습니다. 프로젝트의 Node 서버 엔드포인트는 Pages에서 실행되지 않습니다.

## 보스 이미지

기존 21개와 추가 7개 보스의 실제 게임 초상화를 선택창과 체크리스트에 표시합니다. 로컬 이미지 파일을 함께 배포하며 출처는 [ASSETS.md](ASSETS.md)에 기록했습니다. 이미지 로딩에 실패하면 기존 보스 기호로 대체합니다.

## 검증

`npm test` (22개 테스트)는 12개 제한, 공식 API 헤더·사진 응답·오류 처리와 한국 시간 주간 초기화 경계, 파티별 수익과 캐릭터별 설정 분리, 키 미설정 처리, 모의 Nexon 응답 및 오류 처리, 모든 캐릭터의 4주·5주 및 월간 결정석 예상 수익, 현금 환산, 레벨별 초기 목록, 기본 하드/카오스 난이도, 일괄 체크 제한, 달력 윤년/날짜 경계, 일정 색상·메모 저장 및 복원을 검증합니다. 모의 API 검증은 실제 Nexon 서버 연결을 검증하는 것이 아닙니다.

참고 UI로 제공된 사이트는 개발 환경의 프록시에서 HTTP CONNECT 403으로 접근할 수 없어 직접 확인하지 못했습니다. 현재 화면은 캐릭터 카드, 주간 수익 요약, 보스 체크리스트를 중심으로 구성한 별도 디자인입니다.

## 보스 목록 보완

최초의 대적자, 찬란한 흉성, 벨로나, 림보, 발드릭스, 유피테르와 검은 마법사를 추가했습니다. 난이도와 주간/월간 구분은 ASSETS.md의 공개 참조 데이터를 확인했습니다. 이는 Nexon 공식 사이트를 직접 읽은 검증은 아닙니다.

현재 선택창은 주간 24종과 월간 1종을 제공합니다. 참조 주간 표에서 제외된 힐라·핑크빈·시그너스는 기존 설정과 처치 데이터를 보관하면서 주간 목록/한도 계산에서 제외합니다. 해당 데이터는 내보내기에서 유지됩니다. 신규 캐릭터의 초기 주간 목록은 레벨 입장 조건으로 최대 12종을 선택하며, 기존 사용자 목록은 임의로 다른 보스로 대체하지 않습니다.

최초의 대적자·찬란한 흉성·벨로나·림보·발드릭스·유피테르는 파티 최대 3인, 익스트림 스우는 2인으로 선택을 제한합니다. 기존에 더 많은 인원을 입력했다면 계산할 때 해당 최대 인원으로 제한합니다.
