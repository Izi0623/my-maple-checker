# 메이플 위클리

메이플스토리 캐릭터별 주간 보스 루틴과 결정석 수익을 관리하는 한국어 웹 앱입니다.

## 실행

Node.js 24 이상이 필요합니다. 런타임 의존성이나 빌드 과정은 없습니다.

```sh
npm start
```

기본 포트는 3000입니다. 개발 중 자동 재시작은 `npm run dev`, 검증은 `npm test`를 사용하세요. 클라우드 작업에서는 기존 체크아웃을 사용하며 추가 Git worktree를 만들 필요가 없습니다.

## 사용 방법

1. 내 캐릭터의 `＋` 버튼에서 이름을 입력하고 **직접 등록**합니다. 처음 보이는 캐릭터는 명시적인 데모입니다.
2. **기본 보스 설정**에서 매주 잡는 보스를 선택하고 저장합니다.
3. 보스별 난이도와 파티 인원(1~6명)을 선택합니다. 같은 보스의 난이도는 하나만 선택할 수 있습니다.
4. 보스의 수익 금액을 눌러 결정석 판매가를 수정합니다.
5. 보스 아래 **동행 메모 추가**를 눌러 함께 가는 사람이나 약속 시간을 적습니다. 저장한 메모는 목록에 표시되고, 캐릭터별로 저장되어 다음 주에도 유지됩니다. 메모창에서 수정·삭제할 수 있습니다 (최대 500자).
6. 처치한 보스를 체크하면 `floor(결정석 판매가 / 파티 인원)`을 합산합니다.

**중요:** 포함된 가격은 과거 일반 월드의 참고값이며 최신 가격이나 현재 월드별 가격을 검증한 표가 아닙니다. 화면에서도 이를 표시합니다. 본인의 실제 결정석 판매가를 입력한 후 사용하세요. 수익은 결정석만 포함하며 아이템 드롭 수익은 포함하지 않습니다. 일반/리부트 월드 배율을 자동 적용하지 않습니다.

기본 보스 목록, 가격, 인원과 처치 체크는 캐릭터별로 브라우저 `localStorage`에 저장됩니다. 한국 시간 목요일 00:00부터 새 주로 계산하며, 새 주에는 처치 체크만 새로 시작하고 기본 목록과 가격은 유지합니다. 지난 주 기록은 내보내기 데이터에 보존됩니다. 보스별 변경 사항은 현재 주 수익에 즉시 적용됩니다. 데이터는 브라우저 간에 동기화되지 않습니다. `기록 내보내기`로 JSON 백업이 가능합니다. 가져오기 UI는 아직 제공하지 않습니다.

## GitHub Pages 배포

서버나 API 키 없이 `public/`의 정적 파일만 게시합니다. 캐릭터 이름은 직접 등록하고 보스 기록은 브라우저에 저장합니다. 게임 캐릭터 정보는 자동으로 불러오지 않습니다. 사이트 주소가 달라지면 기존 브라우저 기록은 자동 이전되지 않습니다.

배포용 브랜치를 만들고 올리는 명령:

```sh
# 먼저 public/ 변경 사항을 커밋한 뒤 실행합니다.
npm run deploy:pages
```

이 명령은 현재 커밋의 `public/` 디렉터리만 `gh-pages` 브랜치로 푸시합니다. 강제 푸시는 사용하지 않습니다. 새 Git worktree를 만들거나 현재 체크아웃을 바꾸지 않습니다. GitHub 읽기/쓰기 권한이 필요합니다.

최초 한 번 GitHub 저장소의 **Settings → Pages**에서:

- Source: **Deploy from a branch**
- Branch: **gh-pages**, 폴더: **/(root)**
- **Save**

GitHub가 배포를 완료하면 Pages 설정 화면에서 실제 사이트 URL을 확인하세요. 예상 주소는 `https://izi0623.github.io/my-maple-checher/`이며, 배포 상태를 확인하기 전에는 접속 가능한 주소로 간주하지 않습니다. 저장소가 비공개라면 계정 플랜에 따라 Pages 사용이 제한될 수 있습니다. 이 경우 저장소 공개 여부는 사용자가 결정해야 합니다.

Node 서버의 Nexon 조회 엔드포인트 코드는 남아 있지만 현재 웹 화면은 사용하지 않습니다. GitHub Pages에서는 이 서버가 실행되지 않습니다.

## 검증

`npm test`는 한국 시간 주간 초기화 경계, 파티별 수익과 캐릭터별 설정 분리, 키 미설정 처리, 모의 Nexon 응답 및 오류 처리를 검증합니다. 모의 API 검증은 실제 Nexon 서버 연결을 검증하는 것이 아닙니다.

참고 UI로 제공된 사이트는 개발 환경의 프록시에서 HTTP CONNECT 403으로 접근할 수 없어 직접 확인하지 못했습니다. 현재 화면은 캐릭터 카드, 주간 수익 요약, 보스 체크리스트를 중심으로 구성한 별도 디자인입니다.
