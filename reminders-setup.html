카카오톡으로 보스 약속 알림 받기

본인의 카카오톡 ‘나와의 채팅’에 보스 약속 1시간 전 알림을 보냅니다. 사이트는 GitHub Pages에 그대로 두고, 무료 Google Apps Script가 브라우저를 닫아도 예약 작업을 실행합니다.

처음 한 번 준비할 것

카카오 계정, Google 계정, 카카오 앱의 REST API 키가 필요합니다. Nexon API 키와는 별개의 키입니다. 아래 작업은 본인 계정에서 진행해야 합니다. 아직 설정하지 않았다면 카카오톡 알림은 발송되지 않습니다.

Apps Script는 1분 간격으로 확인하므로 정확히 60분 전 전송을 보장하지 않습니다. Google 실행 지연·서비스 한도·카카오 인증 상태에 따라 늦어지거나 실패할 수 있습니다.

1. 카카오 앱과 API 권한 만들기

  1. Kakao Developers에 로그인하고 내 애플리케이션 → 애플리케이션 추가로 개인용 앱을 만드세요. 이미 카카오 앱이 있다면 사용할 수 있습니다.
  2. 앱의 앱 키 화면에서 REST API 키를 확인하세요. JavaScript 키나 Nexon 키를 사용하지 않습니다.
  3. 웹 플랫폼(또는 앱 키의 웹 플랫폼 설정)에 사이트 도메인 https://izi0623.github.io를 등록하세요.
  4. 카카오 로그인을 활성화하고 Redirect URI에 아래 주소를 정확히 등록하세요.
    https://izi0623.github.io/my-maple-checker/kakao-auth.html
  5. 동의항목에서 카카오톡 메시지 전송 (talk_message)을 설정하세요. 로그인할 때 메시지 전송에 동의해야 합니다. 개인 개발자는 본인(앱 소유자 또는 앱 팀의 등록된 계정)으로 인증하세요.
  6. 카카오 로그인에서 Client Secret 사용이 활성화되어 있다면 그 값도 확인해 Apps Script 속성에 등록합니다. 키와 토큰을 채팅이나 GitHub 코드에 올리지 마세요.

공식 안내: 카카오 로그인 REST API · 나에게 메시지 보내기. 관리 메뉴 명칭은 카카오 콘솔 버전에 따라 달라질 수 있습니다.

2. 무료 예약 실행 프로젝트 만들기

  1. Google Apps Script에서 새 프로젝트를 만드세요. 이름은 ‘메이플 보스 알림’으로 지정하면 됩니다.
  2. 아래 파일을 열고 전체 내용을 복사하여 Apps Script의 Code.gs 기본 코드를 지운 자리에 붙여 넣고 저장하세요.
    예약 실행 코드 다운로드 
    3. 

  3. 왼쪽 톱니바퀴 프로젝트 설정에서 시간대를 Asia/Seoul로 지정하고, 스크립트 속성에 KAKAO_REST_API_KEY = REST API 키를 추가하세요. Client Secret을 사용한다면 KAKAO_CLIENT_SECRET 속성도 추가합니다.
    4. 



3. 본인의 카카오톡에 연결하기
    

  1. 편집기로 돌아가 상단 함수 목록에서 getKakaoLoginUrl을 선택하고 실행하세요. 처음에는 Google 실행 권한 승인 화면이 나옵니다. 직접 만든 프로젝트 이름과 요청 권한(외부 HTTP 요청, 트리거 실행)을 확인하고 승인하세요. 검증되지 않은 개인 프로젝트 안내가 뜰 수 있습니다.
    2. 

  2. 실행 로그에 나온 카카오 로그인 주소를 열고 본인 카카오 계정으로 로그인한 뒤 메시지 전송에 동의하세요.
    3. 

  3. ‘카카오 인증 확인’ 페이지에서 인증 응답 복사를 누르세요. Apps Script 프로젝트 설정의 스크립트 속성에 AUTHORIZATION_RESPONSE = 복사한 JSON을 추가합니다.
    4. 

  4. 편집기에서 connectKakao를 실행하세요. 일회용 인증 코드는 바로 처리해야 합니다. 코드가 만료되면 로그인 주소 생성부터 다시 진행하세요. 성공하면 access/refresh 토큰은 스크립트 속성에 자동 저장되며 인증 응답은 삭제됩니다.
    5. 

  5. 원하면 sendTestMessage를 직접 실행해 테스트하세요. 실제로 카카오톡에 메시지 1개가 발송됩니다. ‘나와의 채팅’에 도착하는지 확인하세요.
    6. 



4. 웹 앱 배포 및 예약 실행 켜기
    

  1. 오른쪽 위 배포 → 새 배포에서 유형을 웹 앱으로 선택하세요.
    2. 

  2. 실행 사용자: 나, 액세스 권한: 모든 사용자로 배포하세요. 본인의 로그인 없이 사이트가 동기화할 수 있어야 합니다. 서버는 별도의 무작위 연결 키가 일치할 때만 일정 변경을 허용합니다. 회사/학교 계정에서 이 옵션이 제한되면 개인 Google 계정을 사용해야 합니다.
    3. 

  3. 생성된 https://script.google.com/macros/s/…/exec 형태의 웹 앱 URL을 복사하세요. /dev 주소를 사용하지 않습니다.
    4. 

  4. 편집기에서 installReminderTrigger를 한 번 실행하세요. 왼쪽 트리거 화면에서 sendDueReminders가 1분 간격으로 등록되었는지 확인하세요.
    5. 

  5. 프로젝트 설정의 스크립트 속성에 자동 생성된 SYNC_KEY를 확인하세요. 이것은 사이트와 예약 실행 서버를 연결하는 키입니다. 다른 사람에게 공유하지 마세요.
    6. 



5. 캘린더에서 연결하기
    

  1. 메이플 보스 사이트의 캘린더 → 카카오톡 알림 설정을 누르세요.
    2. 

  2. 웹 앱 URL과 SYNC_KEY를 입력하고 연결하고 일정 전송을 누르세요.
    3. 

  3. ‘예약 알림 N개 저장 확인’ 메시지를 확인하세요. 시간이 없는 일정과 이미 지난 일정은 예약하지 않습니다. 이후 일정 추가·변경·삭제는 연결된 탭에서 자동 전송됩니다. 실패 안내가 나오면 일정 다시 전송을 누르세요.
    4. 

  4. 연결 정보는 이 탭의 sessionStorage에 보관하며 카카오 토큰은 Apps Script에만 저장됩니다. 같은 탭 새로고침은 유지되지만 탭을 닫은 후 일정을 수정할 때는 다시 연결해야 합니다. 예약 서버에 이미 전송된 일정은 탭을 닫아도 실행됩니다.
    5. 

  5. 중지하려면 연결 설정의 서버 예약 알림 중지를 누르세요. 카카오톡 API는 친구가 아닌 본인에게만 전송합니다.
    6. 



사용할 때 알아둘 점
    

  • 시간은 한국 시간입니다. 알림은 19:00 ≫ 달빛님 / 하드 루시드 형태의 일정 내용을 포함합니다. 약속까지 1시간이 채 남지 않은 시점에 새로 전송하면 다음 예약 실행 시 알립니다.
    • 

  • 한 일정은 정상 전송 후 반복 발송하지 않습니다. 실패하면 최대 3회 시도합니다. 통신 응답이 유실된 경우 중복 발송 가능성이 있으며 정확한 1회 전달을 보장하지 않습니다.
    • 

  • refresh 토큰으로 access 토큰을 갱신합니다. 카카오 동의 철회·장기 미사용·refresh 토큰 만료 시 3단계 인증을 다시 진행해야 합니다.
    • 

  • 변경 또는 삭제 후 서버 저장 확인을 받아야 기존 예약도 변경됩니다. 다른 브라우저의 일정과 자동 병합하지 않으므로 일정은 주로 사용하는 한 브라우저에서 관리하세요.
    • 

  • 작동하지 않으면 Apps Script 실행 화면과 스크립트 속성의 LAST_SEND_ERROR, LAST_SYNC_AT을 확인하세요. 코드 수정 후에는 배포 관리 → 수정 → 새 버전으로 웹 앱 배포도 갱신하세요.
    •
